DEPLOY — STEP 1: APPS SCRIPT
-----------------------------
Google Sheet > Extensions > Apps Script
Open Code.gs.
Replace the ENTIRE old Code.gs with:
    google-backend/Code.gs
Save.

Then:
Deploy > Manage deployments > Edit (pencil) > Version: New version > Deploy
IMPORTANT: Update the existing deployment. Do not create a new deployment, so your current /exec URL remains unchanged.

Existing backend URL configured in website:
https://script.google.com/macros/s/AKfycbxnjTu6umxT2akEGnlLh-F2Nsq-r_3LrkMDr-NXl3ErvVYLAEcjk7W8zCp6lBDEoUGt8A/exec

For an already initialized Queshift sheet, initQueshiftSystem does NOT need to be run again for this update.
For a completely new sheet/project only, run initQueshiftSystem once.
