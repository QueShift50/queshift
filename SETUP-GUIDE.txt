QUESHIFT V4 — GOOGLE SHEETS + DRIVE + GITHUB PAGES SETUP
========================================================

IMPORTANT
---------
• Admin Google account: info.queshift@gmail.com
• Domain: https://queshift.in
• Never write an admin password in HTML, JavaScript, Google Sheet or GitHub.
• Customer and admin login both use Google's secure Sign in with Google button.

PART A — GOOGLE SHEET AND APPS SCRIPT (Steps 1–3)
-------------------------------------------------
1. Login to info.queshift@gmail.com. Create one blank Google Sheet named
   "Queshift Website Database". Open Extensions > Apps Script.

2. Delete the sample code from Code.gs, then copy all code from:
   google-backend/Code.gs
   In Apps Script Project Settings, enable "Show appsscript.json manifest file",
   then replace its content with google-backend/appsscript.json.

3. Select and Run the function initQueshiftSystem once. Accept the Google
   permissions. It creates all database tabs and the "Queshift Website Data"
   Drive folders automatically.

PART B — GOOGLE LOGIN CLIENT ID (Steps 4–6)
--------------------------------------------
4. Open Google Cloud Console with the same Google account. Create/select a
   project, configure the OAuth consent screen, then create an OAuth Client ID:
   Application type = Web application.

5. Add these Authorized JavaScript origins exactly (no path after domain):
   https://queshift.in
   https://www.queshift.in
   Copy the Client ID ending in apps.googleusercontent.com.

6. Apps Script > Project Settings > Script Properties:
   GOOGLE_CLIENT_ID = paste the same Client ID
   Optional: YOUTUBE_API_KEY = YouTube Data API v3 key

   Open assets/js/config.js and paste the same Client ID in googleClientId.

PART C — DEPLOY THE GOOGLE BACKEND (Steps 7–9)
------------------------------------------------
7. Apps Script > Deploy > New deployment > Web app:
   Execute as = Me
   Who has access = Anyone
   Click Deploy and copy the /exec Web app URL.

8. Open assets/js/config.js. Paste that URL in apiUrl. Do not use the /dev URL.

9. Upload the Queshift software file into the Drive folder:
   Queshift Website Data > Software
   Copy its Drive FILE ID. In the SETTINGS tab of the Google Sheet, put the ID
   beside SOFTWARE_FILE_ID. Do not make the software file public. Approval code
   grants access only to the approved customer's Google email.

PART D — GITHUB UPLOAD (Steps 10–12)
------------------------------------
10. Upload every file and folder from this ZIP to the ROOT of the existing
    QueShift50/queshift repository. Keep index.html, CNAME and assets at root.

11. GitHub repository > Settings > Pages:
    Source = Deploy from a branch
    Branch = main and /(root)
    Custom domain = queshift.in
    Keep Enforce HTTPS enabled.

12. Wait for GitHub deployment. Open https://queshift.in/admin.html and sign in
    only with info.queshift@gmail.com. Add logo, favicon, banners, co-owner/team photos,
    brands, social links, YouTube video, invoice details and payment QR.

FINAL AUTOMATION
----------------
Apps Script > Triggers > Add Trigger:
Function = expireSubscriptions
Event source = Time-driven
Type = Day timer
Run = once every day

This automatically expires old plans and removes Drive download permission.

PAYMENT AND INVOICE WORKFLOW
----------------------------
Customer Google Login > Profile > Plan > GST calculation > QR payment > Upload
screenshot > Pending Approval > Admin verifies > Approve > Drive permission +
subscription + GST invoice PDF + welcome email.

SECURITY NOTES
--------------
• GitHub Pages is only the public frontend; customer/payment/invoice rows live
  in your private Google Sheet.
• Payment screenshots and software stay private in Google Drive.
• Public logo/banner/blog images are link-viewable so browsers can display them.
• Never paste Google password, API secret, bank PIN or OTP into GitHub.
