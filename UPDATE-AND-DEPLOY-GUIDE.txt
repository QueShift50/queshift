PART A — UPDATE THE EXISTING GOOGLE APPS SCRIPT
============================================================

STEP 1
1. Open the existing "Queshift Website Database" Google Sheet.
2. Open Extensions → Apps Script.
3. Open the existing Code.gs. Do NOT create another Apps Script project.

STEP 2
1. Select all old Code.gs code and replace it with:
   google-backend/Code.gs
2. Click Save.
3. From the function list select initQueshiftSystem and click Run.

Running initQueshiftSystem again is safe. It keeps old records and creates
only the missing new tabs:

HELP_ARTICLES
QUERIES
QUERY_REPLIES
OTP_LOG
TRIAL_DOWNLOADS
AI_CHAT_LOG

Allow permissions if Google asks again.

STEP 3 — UPDATE THE SAME WEB APP DEPLOYMENT
1. Click Deploy → Manage deployments.
2. Open the existing Web App deployment with the pencil/Edit icon.
3. Version: New version → Deploy.

Keep these settings:
Execute as: Me
Who has access: Anyone

Do not create a second Apps Script project. Editing the existing deployment
keeps the same Web App URL. Copy that URL after deployment.

PART D — ADMIN SETTINGS AFTER DEPLOYMENT
============================================================

STEP 1
1. Open https://queshift.in/admin.html
2. Sign in with info.queshift@gmail.com.
3. Open Client Queries and check the test ticket.

STEP 2
1. Type a response in the query card.
2. Click Send Email Response.
3. Confirm the colourful response email reached the client.

STEP 3 — ADD TRIAL SOFTWARE LATER
1. Admin → Brand & Social → Trial Download Settings.
2. Paste the Google Drive or MEGA HTTPS download URL.
3. Set Software Version, Trial Days, System Requirement and instructions.
4. Click Save Trial Settings.

Until a valid Trial Download URL is saved, the public page shows
"Trial Download: Coming Soon". OTP registration remains open so the verified
email/phone is saved. When the URL is added later, that same email OR phone
can return once and receive the one-time trial download.

SECURITY NOTE
============================================================

OTP_LOG stores an OTP hash, expiry, attempts and verification status—not
the readable OTP. The website never places the private trial URL in HTML.
After the storage provider starts the final download, file redistribution
must also be controlled by the Queshift machine-based 15-day activation.
